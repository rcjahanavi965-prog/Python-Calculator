# 🧮 Python Calculator

A simple command-line calculator built using Python.

## Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ❌ Handles division by zero
- 🔄 Menu-driven interface

## Technologies Used
- Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run:

```bash
python calculator.py
```

## Sample Output

```
===== Python Calculator =====

1. Add
2. Subtract
3. Multiply
4. Divide
5. Exit
```
